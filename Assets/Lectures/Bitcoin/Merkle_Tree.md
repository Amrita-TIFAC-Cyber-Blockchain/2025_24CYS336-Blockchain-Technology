## Merkle Tree
**Merkle Tree** is a tree-like construction in which every leaf node is labelled with the cryptographic hash of a data, and every non-leaf node is labelled with the cryptographic hash of the labels of its child nodes. 
Merkle Tree is used in Blockchain and other applications, which allows efficient and secure verification of the data of large data structures.
